# 포스터 디자인 도구 - 작업 기록

## 2026-10-27 — 첫 시제품 및 갤러리·컬러 도구 개편

### 프로젝트

- 사이트: https://poster-room-reay827.finepond132.chatgpt.site/
- GitHub: https://github.com/reay827/poster-design-tool
- 로컬 작업 폴더: `C:\Users\g\Desktop\gpt\poster-design-tool`
- 로그인 후 이용하는 비공개 사이트로 배포했다.
- 사진·글을 배치하고, 레퍼런스에서 색을 가져와 자신의 포스터로 만드는 브라우저 시제품이다.

### 오늘 정한 방향

- 첫 화면은 편집기 대신 레퍼런스 갤러리로 한다.
- 상단 메뉴는 레퍼런스 / 컬러 / 포스터 만들기 / 내 라이브러리로 구성한다.
- 포스터가 크게 보이는 흰색·연회색 화면과 간결한 설명을 사용한다.
- 참고 사이트의 포스터나 이미지는 가져오지 않는다. 탐색 방식과 도구의 작동 방식만 참고한다.
- 샘플 포스터는 도형과 글자를 이용해 직접 제작한 12개로 구성했다.

### 참고 사이트와 참고한 부분

- https://themovingposter.com/ — 작품을 크게 보여주는 포스터 중심 갤러리.
- https://colorhunt.co/ — 팔레트 탐색과 스타일 필터.
- https://utilzip.com/tools/color-mixer — 두 색 사이의 단계별 중간색.
- https://colorkit.wooahouse.com/ — 색 추출, HEX/RGB/HSL, 색상 조합 도구.

### 구현한 기능

- 사진·글 프레임 추가, 이동, 모서리 크기 조절, 복제·삭제·겹침 순서.
- 중앙 및 다른 프레임의 가장자리·중심 스냅, 실행 취소·다시 실행.
- 사진 채우기·전체 보기, 내부 위치·확대 비율 조정.
- 글 내용·글꼴·크기·색·정렬·줄 간격 설정과 넘침 안내.
- 용지 비율·사용자 지정 픽셀 크기, 가이드 없는 RGB PNG 다운로드.
- 브라우저 IndexedDB에 작업·빈 레이아웃 템플릿 저장, JSON 백업·복원.
- 자체 제작 샘플 12개, 스타일 필터, 포스터 즐겨찾기와 상세 보기.
- 개인 이미지 업로드 및 대표 색상 5개 추출.
- HEX/RGB/HSL 확인·복사, 색 하나 및 팔레트 저장·적용.
- 두 색을 5/8/12/16/20단계로 혼합.
- 유사색·보색·삼색·명도 조합 생성, 색 잠금 및 재추천.
- 선택한 레퍼런스를 편집기 옆에서 참고하는 패널.
- 사용자 피드백에 따라 카테고리 글자를 PC 14px / 작은 화면 13px로 확대. 상단 메뉴·컬러 탭과 버튼 여백도 조정.

### 확인한 내용과 한계

- JavaScript 구문 검사 통과.
- 브라우저에서 글 추가·실행 취소, 레퍼런스 탐색·팔레트 저장 확인.
- 상세 보기 → HEX/RGB/HSL 확인 → 팔레트 적용 → 편집기 참고 패널 확인.
- 검정·흰색의 8단계 RGB 혼합값과 잠근 색의 재추천 시 유지 확인.
- 배포 성공 및 GitHub main 반영 확인. 마지막 UI 변경 커밋: `b792e70`.
- 사진 업로드·작업 저장/재열기·PNG 다운로드·백업 복원 전체를 끝까지 검증한 상태는 아니다. 다음 작업에서 실제 사진으로 흐름을 확인한다.
- A3/A4는 용지 비율용이며, 출력은 표시된 픽셀 크기의 RGB PNG다. 인쇄용 300dpi·CMYK·PDF는 아직 지원하지 않는다.
- 사용자 카테고리 관리, 다중 선택, 기기 간 동기화는 아직 구현하지 않았다.
- 브라우저 데이터를 지우면 저장 항목도 사라질 수 있으므로 JSON 백업 기능을 사용한다.
