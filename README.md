# Poster Room

사진과 글을 배치하고 레퍼런스에서 팔레트를 가져오는 브라우저 포스터 편집기 시제품입니다.

## 실행

Node.js에서 `npm run dev` 후 http://127.0.0.1:5173 을 엽니다. 추가 패키지 설치는 필요하지 않습니다.

## 지원 기능

- 사진·글 프레임 추가, 이동, 모서리 크기 조절, 복제·삭제·겹침 순서
- 중앙·다른 프레임 가장자리/중심 스냅, 실행 취소·다시 실행
- 사진 채우기/전체 보기, 내부 위치와 확대 비율 조정
- 글 내용·글꼴·크기·색·정렬·줄 간격, 넘침 안내
- 용지 비율 선택, 사용자 지정 픽셀 크기, 가이드 없는 PNG 출력
- IndexedDB 작업·빈 레이아웃 템플릿 저장, JSON 백업·복원
- 자체 제작 레퍼런스 그래픽, 개인 이미지 업로드·대표 색상 추출, 팔레트 저장·적용·HEX 복사

## 시제품 범위

출력은 화면에 표시하는 픽셀 크기의 RGB PNG입니다. A3/A4 프리셋은 비율용이며 인쇄용 300dpi 출력은 아닙니다. 브라우저 저장 데이터는 기기 간 동기화되지 않습니다. 레퍼런스 색상은 양자화된 대표값입니다. 사용자 카테고리 관리와 다중 선택은 아직 구현하지 않았습니다. 외부 Google Fonts 연결 실패 시 시스템 글꼴을 사용합니다.

## 검증

`npm run check`로 JavaScript 구문을 확인합니다. 브라우저에서 사진 업로드 → 이동·크기 조절 → 저장 → 라이브러리에서 열기 → PNG 다운로드 → JSON 백업 복원을 확인하세요.

## 갤러리·컬러 업데이트

- 자체 제작 포스터 12개, 스타일 필터, 포스터 즐겨찾기, 상세 보기
- HEX/RGB/HSL 확인·복사, 단일 색상 및 팔레트 저장
- 팔레트 탐색, RGB 중간색 5/8/12/16/20단계 혼합
- 유사색·보색·삼색·명도 조합, 색 잠금 및 재추천
- 레퍼런스 팔레트 적용과 편집기 참고 이미지 패널
- 외부 사이트의 포스터·이미지를 복사하거나 수집하지 않습니다. 샘플은 Canvas 도형·타이포그래피로 직접 그립니다.

검증: 브라우저에서 갤러리 → 상세 → 색상 정보 → 팔레트 적용 → 편집기 참고 패널, 흰색/검정 8단계 혼합, 색 잠금 후 재추천을 확인했습니다.
